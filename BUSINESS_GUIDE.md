# LifeHub business guide

This guide explains the app in plain language for non-developers.

## 1. What each screen does

### Dashboard

The dashboard is the home screen after login. It helps you quickly see what matters most: upcoming birthdays, events, tasks, and your current financial picture.

### Events / Moments

This is the main life-planning area. You can create memorable events such as birthdays, anniversaries, festivals, travel plans, and personal celebrations. Each event can include notes, follow-up tasks, files, and financial links.

### Activities

Activities are the tasks that support an event. For example, a birthday might need a shopping task, reminder task, or booking follow-up.

### Memories

Memories help preserve the story of a moment. This could be a note about why a date matters, a photo, a keepsake, or a written reflection.

### Expenses

This area tracks outgoing money. You can record what you spent, what the expense was for, and which event or task it relates to.

### Income

This area tracks money coming in. It is useful for understanding your overall financial position.

### Settings

Settings let you customize the app to fit your personal routine. You can change default categories, reminder times, theme, and financial defaults.

### Code Lists

Code lists are the categories behind the app. Examples include event types, expense categories, reminder presets, and income types.

## 2. What data is stored

LifeHub stores information such as:

- important dates and events
- activity checklist items
- personal notes and memories
- files and attachments
- money spent and money received
- user preferences and default choices

## 3. How Moments work

A Moment is a big personal milestone or event. It may be a birthday, anniversary, celebration, family day, or another event the user wants to remember. Each moment can contain:

- title and date
- category type
- notes
- tasks
- files or keepsakes
- related spending

## 4. How Activities work

Activities help turn an event into a plan. They are the “to-do” items connected to an occasion. This makes it easier to manage preparation without losing the event itself.

## 5. How Memories work

Memories add emotional value to each event. They are the part of the record that explains why the event matters, not just when it happens. This can help users remember the story and significance behind milestones.

## 6. How Expenses work

Expenses are your spending records. They can be anchored to a moment, a task, or simply tracked as part of your personal finances. The app keeps a clear overview of total spending and recent trends.

## 7. How Settings work

Settings are the control center for customizing the app. They let you define how categories are named, what default values are used, what reminder times you prefer, and how the dashboard should look.

## 8. How Code Lists work

Code lists give the app reusable categories and labels. Instead of hard-coding everything, these lists can be adjusted by the user so the app matches their personal terminology and life patterns.

## 9. Common maintenance tasks

Typical maintenance tasks include:

- updating default categories after life changes
- adding new event types
- adjusting reminder times
- exporting a backup before major changes
- reviewing expenses and upcoming milestones each month
- refreshing the app after a new release

## 10. How the app helps everyday life

LifeHub is designed to reduce mental load. It keeps important dates, plans, memories, and personal finances in one place so users can focus on living rather than managing scattered notes and separate tools.
